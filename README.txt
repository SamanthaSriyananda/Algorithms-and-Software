This program can be used to determine whether a given wireless mobile device/UE is within a given cell coverage area.
1. In 3DCellOGLplot08.cpp, select the line 60 or 62 based on the algorithm you want to use to determine the location.
	Two algorithms: Ray Casting, Winding Number
2. Compile 3DCellOGLplot08.cpp and follow the instructions
3. The program uses GPU acceleration to improve performance while efficiently managing memory and computational resources. Performance monitoring tools can be used to monitor GPU/CPU usage during rendering.

Note: For the convenience of those who have not configured their programming environments for GPU coding, an .exe is included.
